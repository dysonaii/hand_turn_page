# 手勢翻頁

給閱讀 App（微信讀書等）用的手勢翻頁工具：前鏡頭看手，不用碰手機。免 root，靠無障礙 `dispatchGesture` 點螢幕；辨識用 MediaPipe HandLandmarker（離線）。

## 功能一覽

| 想做什麼 | 在哪操作 | 會發生什麼 |
|---|---|---|
| 下一頁 | 鏡頭前握拳頭 | 點一下螢幕右中 |
| 上一頁 | 鏡頭前比剪刀（食指+中指） | 點一下螢幕左中 |
| 開始/暫停翻頁 | 閱讀頁點懸浮球（▶→❚❚） | 開/關前鏡頭；球 2 秒內自癒，不會消失；自家設定頁點球無反應 |
| 看鏡頭有沒有看到手 | 懸浮預覽窗 | 跟相機同開同關；照鏡子（舉右手，像舉左手）；手掌畫綠圈（不翻，只當換手勢解鎖），剪刀畫黃圈，拳頭畫紅圈；本體拖移，右下角拖縮放；大小共用記住，位置直屏/橫屏分開記 |
| 喬角度 | 設定頁「手勢測試開/關」 | 30 秒小窗預覽＋辨識狀態，手掌/剪刀會 Toast（不翻頁） |
| 調連翻間隔 | 設定頁「翻頁冷卻」1~30 秒 | 預設 3 秒；冷卻內手勢丟掉 |
| 人走開自動停 | 設定頁「閒置自動停」1~30 分鐘 | 預設 5 分鐘沒翻頁：關相機＋停球＋關小窗；自己用手滑頁也算活著，會重數 |
| 只在特定 App 翻 | 設定頁「選擇可翻頁的 App」 | 預設只勾微信讀書；全不勾＝全部允許 |
| 調懸浮球深淺 | 設定頁「懸浮球透明度」10~100% | 即時生效 |
| 調預覽窗大小深淺 | 設定頁「預覽窗大小」80-400dp／「透明度」10-100% | 預設 200x150；拖縮放放開自動記住 |
| 回設定頁改東西 | 長按懸浮球 600ms | 跳回設定頁；回設定頁自動停本次會話 |
| 橫屏也在翻 | 把手機轉橫 | 點位重算，預覽窗轉正跟著轉 |

## 翻頁規則（四條）

1. 拳頭入鏡：下頁；剪刀入鏡：上頁；手掌只亮綠圈不翻（四指伸就算，手心、手背皆可）。
2. 拳頭↔剪刀、手掌→拳頭/剪刀直切即翻，不用出鏡。
3. 同手勢一直比著只翻一次（換手勢或出鏡後再比）。
4. 出鏡清鎖：手離開鏡頭再入鏡，重新起算。

## 安全停止（不用記，自動的）

* 相機只在 AND 才開：無障礙開＋翻頁服務開＋球點火＋前景在白名單內。
* 自家設定頁／非白名單 App／桌面：關鏡頭＋關預覽窗＋藏球（球只出現在自家和白名單）。
* 手勢被系統拒收（金融／遊戲頁）：自動停，免得空轉。

## 開始使用（3 步）

1. 開 App →「1. 開無障礙權限」→ 啟用 手勢翻頁；「2. 開懸浮窗權限」→ 允許；「3. 開相機權限」→ 允許。
2. 按「手勢測試開/關」看小窗，拳頭/剪刀有反應才繼續（喬角度用）；設冷卻、選白名單 App → 按「開啟翻頁服務」（只掛球，不開鏡頭）。
3. 進閱讀 App 內文頁 → 點球變 ❚❚ 開鏡頭＋預覽窗；再點（▶）即停。

## 常見問題（看症狀）

* **比了不翻**：手有沒有進小窗；同手勢鎖住中（換手勢或出鏡再比）；冷卻還沒過；白名單有沒有勾該 App。
* **小窗人像是歪的／鏡像反了／紅圈套偏**：報方向（豎屏／橫屏充電口左右）＋現象，轉正、鏡像、紅圈座標都按機型調（realme GT Neo2 已調正）。
* **球 ❚❚ 但不翻**：剛切進書頁 3 秒內是校準期，等一下；球不見的話 2 秒看門狗會自己長回來。
* **每次 Run 都要重開無障礙**：完整解除安裝會清系統綁定，屬 Android 設計。改用 `adb install -r` 覆蓋；Apply Changes 不會重啟跑著的無障礙服務（小窗仍是舊碼）——以「比拳頭有紅圈」為準確認新碼在跑。

## 模型檔（編譯前必放）

`app/src/main/assets/hand_landmarker.task` 沒進 git（約 8MB），直接抓官方檔放進 `app/src/main/assets/`：

`https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task`

沒放的話開鏡頭會 Toast 提示，不會炸。

## 開發者

* 環境：Android Studio＋ SDK API 34；手機 Android 8+（`minSdk 26`）。
* 檔案：`MainActivity.kt`（設定頁）／`PageTurnService.kt`（門控／手勢輸出／懸浮球／相機生命週期／預覽窗／2 秒看門狗）／`HandTracker.kt`（Camera2 前鏡頭＋MediaPipe＋幾何分類＋預覽轉正＋手心座標回調）／`res/xml/accessibility_service_config.xml`。
* 自檢：`HandTracker.demo()` 驗幾何規則（拳頭=1／剪刀=2／手掌=3／讚=0），無需相機。
